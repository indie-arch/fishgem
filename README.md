# Fishgem

A cozy 2D fishing and social game inspired by *WEBFISHING*.

Explore, catch and collect fish, sell what you find, and purchase upgrades.

## Getting started

1. Install [Godot 4.7](https://godotengine.org/).
2. Clone this repository.
3. Open `project.godot` in Godot.
4. Run the project with <kbd>F6</kbd>.

Fishgem is an early work in progress.
